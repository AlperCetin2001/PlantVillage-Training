# Plant Disease Detection Project

This is a Deep Learning project for classifying plant diseases using the PlantVillage dataset. It uses MobileNetV2 architecture with Transfer Learning.

## Installation

1. **Download this Repository:**
   Click on the green `Code` button and select `Download ZIP`. Extract it.

2. **Install Requirements:**
   Open your terminal/command prompt in this folder and run:
   ```bash
   pip install -r requirements.txt
